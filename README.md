# 🏥 Hospital Appointment System

A modern and responsive **Full Stack Hospital Appointment System** built to simplify the process of booking medical appointments online. The application provides a secure platform where patients can register, log in, browse doctor profiles, schedule appointments, select preferred dates and time slots, and manage their appointment history. It features JWT-based authentication, password encryption using bcrypt, secure REST APIs, and image upload functionality for doctor and patient profiles.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/TharanishM/hospital-appointment-system.git
cd hospital-appointment-system
```

## Backend

```bash
cd backend
npm install
npm run dev
```


## Frontend

```bash
cd frontend
npm install
npm run dev
```
